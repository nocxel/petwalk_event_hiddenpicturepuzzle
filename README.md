# 🍂 PETWALK 가을맞이 숨은그림찾기 웹 이벤트

애견용품 셀렉트샵 **PETWALK**의 가을맞이 숨은그림찾기 웹 이벤트 및 15% 할인 쿠폰 발급 웹 애플리케이션입니다.

---

## 🐶 주요 기능

1. **'월리를 찾아서' 스타일 고밀도 가을 페스티벌 일러스트**:
   - 수백 마리의 반려견과 견주들이 북적이는 활기찬 가을 반려동물 대축제 풍경
   - 마틴 핸드포드(Where's Waldo) 특유의 아기자기한 미니어처 핸드드로잉 스타일
2. **숨은 5대 핵심 맞춤 순간 찾기**:
   - **목줄 한 강아지 (Walk & Safety)**: 단풍길을 산책하는 댕댕이 (아이캔더, 분독, 젠틀우프 등)
   - **차 탄 강아지 (Drive & Comfort)**: 숲길 도로를 달리는 빨간 승용차 창문 밖 강아지 (스윗테일, 올치)
   - **이동가방 강아지 (Travel & Carrier)**: 피크닉 돗자리 위 열린 이동가방 속 댕댕이 (아이캔더, SSFW, 리카리카 등)
   - **간식 당기는 두 댕댕이 (Healthy Treats)**: 뼈다귀 간식 1개를 사이좋게 물어뜯는 두 마리 (스위피, 트러스티푸드 등)
   - **원반 낚아채는 강아지 (Play & Fun)**: 도그런에서 빨간 원반을 향해 점프하는 댕댕이 (터그놀이, 장난감)
3. **상품 발견 시 팝업 모달**:
   - 해당 카테고리 대표 입점 브랜드 나열
   - [계속 찾기] 버튼을 통한 연속적인 게임 몰입 유도
4. **15% 할인 쿠폰 즉시 발급**:
   - 실물 티켓형 영수증/쿠폰 디자인
   - 고유 쿠폰 식별번호 난수 발급 및 유효기간(30일) 자동 계산
   - **"※ 매장 할인과 중복으로 적용되지 않습니다."** 안내 명시
5. **📸 [화면 캡처하기 (이미지로 저장)] 원클릭 버튼**:
   - `html-to-image` 고화질 PNG 이미지 생성으로 고객 스마트폰 갤러리에 원클릭 자동 저장
   - **"📌 매장에서 계산할 때 직원에게 이 화면(또는 캡처본)을 보여주세요"** 명시
6. **모바일 & 터치 전용 캔버스 엔진**:
   - 핀치 줌 & 더블 탭 확대 (1.0x ~ 3.2x), 부드러운 드래그(Pan) 이동
   - 드래그와 클릭을 정확히 구분하여 오클릭 방지
   - 확대 시 현재 시점 위치를 보여주는 미니맵 레이더 뷰파인더 탑재
   - 새로고침 시에도 찾은 기록과 쿠폰이 안전하게 유지되는 LocalStorage 지원

## 🌐 Vercel 배포 및 `event.petwalk.kr` 도메인 연결 가이드

### 1단계: GitHub에 소스코드 올리기
1. [GitHub](https://github.com)에서 새로운 Repository 생성 (예: `petwalk-event`)
2. 프로젝트 폴더에서 git 푸시:
   ```bash
   git init
   git add .
   git commit -m "feat: PETWALK 숨은그림찾기 이벤트 웹앱"
   git branch -M main
   git remote add origin <깃허브_리포지토리_주소>
   git push -u origin main
   ```

### 2단계: Vercel 배포
1. [Vercel](https://vercel.com)에 로그인 후 **"Add New..." ➔ "Project"** 클릭
2. 방금 올린 `petwalk-event` 리포지토리를 선택하고 **"Deploy"** 클릭
3. 별도 환경변수 설정 없이 1~2분 내 배포 완료!

### 3단계: `event.petwalk.kr` 서브도메인 연결
1. Vercel 프로젝트 대시보드 ➔ **Settings ➔ Domains** 이동
2. `event.petwalk.kr` 입력 후 **Add** 클릭
3. Vercel 화면에 표시되는 DNS 레코드 정보를 복사:
   - **Type**: `CNAME`
   - **Name (호스트)**: `event`
   - **Value (값/대상)**: `cname.vercel-dns.com`
4. 본인의 도메인 등록업체(가비아, 후이즈, 네임체프, 클라우드플레어 등)의 `petwalk.kr` DNS 설정 페이지에 해당 CNAME 레코드를 추가하면 5~10분 내로 `https://event.petwalk.kr`로 접속됩니다.
